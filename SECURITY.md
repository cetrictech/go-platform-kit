# Security policy

This SDK is unreleased and has no supported production release series yet. Report security issues privately through the repository maintainer's GitHub security advisory channel; do not include credentials or exploitable details in public issues. If private reporting is unavailable, contact the maintainer privately before disclosure.

Never commit production keys, tokens or connection strings. Local integration credentials are test-only. See docs/security.md for boundaries and deployment requirements. Maintainers must review vulnerability scan results and relevant real-service security tests before release.
